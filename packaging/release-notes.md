## Herunterladen

| System | Datei | |
| --- | --- | --- |
| **Windows 10/11** | `YT-Music-MP3-windows-x64-Setup.exe` | Doppelklick, fertig – die App startet sofort. |
| **Linux** (alle Distributionen) | `YT-Music-MP3-linux-x86_64.AppImage` | Ausführbar machen, starten. |
| **Debian / Ubuntu / Mint** | `YT-Music-MP3-linux-amd64.deb` | `sudo apt install ./YT-Music-MP3-linux-amd64.deb` |
| **Android 10+** (fast alle Handys) | `YT-Music-MP3-android-arm64.apk` | Ältere 32-Bit-Handys: `…-armv7.apk` |

Alles ist dabei – kein Python, kein ffmpeg, kein Konto nötig.

### Gut zu wissen

- **Windows** zeigt beim ersten Start evtl. „Der Computer wurde durch Windows geschützt“, weil die App
  nicht kostenpflichtig signiert ist: **Weitere Informationen → Trotzdem ausführen**.
- **Android** fragt beim Installieren, ob der Browser/Dateimanager Apps installieren darf – einmal erlauben.
  Links kommen am schnellsten über **Teilen → YT Music MP3** aus der YouTube-Music-App.
- **AppImage**: `chmod +x YT-Music-MP3-linux-x86_64.AppImage && ./YT-Music-MP3-linux-x86_64.AppImage`
- Die Prüfsummen stehen in `SHA256SUMS.txt`.

Nur für Inhalte verwenden, an denen du die Rechte besitzt.
